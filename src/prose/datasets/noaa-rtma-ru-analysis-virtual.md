### Construction

This dataset is constructed by concatenating NOAA's RTMA Rapid Update (RTMA-RU) analyses along the time
dimension, using virtual references to the source GRIB files.

### Source

Source files are provided by [NOAA Open Data Dissemination](https://www.noaa.gov/information-technology/open-data-dissemination)
in the public [NOAA RTMA archive](https://registry.opendata.aws/noaa-rtma/).

### Data availability

Total cloud cover is available from 2020-07-28 00:00 UTC. Earlier positions are missing.
